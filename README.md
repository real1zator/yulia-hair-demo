# Юлия · студия волос

[Открыть демо](https://real1zator.github.io/yulia-hair-demo/)

Объёмная фотопримерка с вращением, наклоном, масштабированием и восемью оттенками, калькулятор и тестовая запись. Заявки сохраняются только в браузере.

Для анимации используется GSAP. Фотореалистичные кадры сгенерированы для демо.
